## Overview

**DataVista** is a clean and professional frontend dashboard project designed to showcase modern UI engineering skills. It combines elegant design with practical functionality by visualizing real-time data through interactive charts, KPI cards, and a dynamic data table.

Built as a recruiter-friendly portfolio project, DataVista focuses on both **visual polish** and **technical quality**, featuring a structured multi-file setup, responsive layout, theme switching, chart animations, API-driven updates, and downloadable reports.

## Key Highlights

- Real API-powered dashboard experience
- Interactive **line**, **bar**, **area**, and **donut** charts
- Statistics cards with live data summaries
- Weekly, monthly, and quarterly filtering
- Custom date range picker
- Downloadable **CSV** and **JSON** reports
- Fully responsive admin dashboard layout
- Dark and light mode support
- Smooth transitions and hover interactions
- Clean card-based UI with professional styling
- Error handling and loading states for better UX

## Why this project stands out

DataVista is more than just a chart dashboard. It demonstrates the ability to:
- Build a scalable frontend structure with separate HTML, CSS, and JavaScript files
- Integrate external APIs and transform data into meaningful visual insights
- Design polished and modern dashboard interfaces
- Create responsive, user-friendly experiences across devices
- Deliver a GitHub-ready project suitable for portfolios and interviews
